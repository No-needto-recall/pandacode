# 简体中文本地化

## 范围

本地化面向 Windows 桌面客户端与 iOS / Android 手机客户端。界面默认使用简体中文，设置中可切换到 English；桌面多个窗口使用同一偏好，手机偏好独立保存。应用语言不决定 AI 模型回复语言，也不会修改历史对话。

切换语言不会重启任务或清空草稿。主界面与支持重绘的面板即时更新；已经打开的通用确认弹窗、选择菜单和已经显示的短暂通知保留打开时的文案，关闭后重新打开或收到新通知时使用新语言，避免为了翻译而重置尚未提交的表单。

官网、机器人独立网页聊天、外部登录页面、第三方 CLI 输出和用户文档不在此范围。原生系统对话框中由操作系统提供的按钮遵循系统语言。

## 词典维护

唯一源文件在 `shared/i18n/`：

- `core.ts`：无平台依赖的翻译和格式化工具。
- `catalogs/common.json`：跨端通用文案。
- `catalogs/desktop-*.json`：桌面领域词典。
- `catalogs/mobile.json`：手机文案。

词条使用语义键，并提供 `en`、`zh-CN` 两种语言。动态句子使用 `{name}` 形式的参数；必须在两种译文中保留同一组参数。不要按英文词序拼接翻译片段。

运行 `npm run i18n:generate` 更新两端 `src/i18n-generated/`；不要直接修改生成文件。运行 `npm run i18n:check` 检查同步状态。`npm run i18n:audit` 用 TypeScript AST 列出界面属性、HTML 模板与 JSX 中的候选英文，供人工核对；品牌、代码示例和协议可能被报告，不能机械替换，也不能把候选数当成完整覆盖率。桌面生成物不包含手机专有词条，手机也不包含桌面专有词条，避免 Metro 解析桌面源码和多余资源。

翻译函数返回纯文本，不负责 HTML 转义。放入 HTML 模板的动态内容仍须使用现有 `escape()`；不要把 HTML 或未经转义的用户内容写进词条。数字、日期和相对时间须使用应用语言，但不改变原有时间戳或时区语义。

## 术语与边界

| 英文 | 中文 |
| --- | --- |
| Task | 任务 |
| Conversation / session | 会话（按具体语境区分） |
| Workspace | 工作区 |
| Worktree | 工作树 |
| Agent | 智能体 |
| Harness | 运行器 |
| Stage / staging files | 暂存（文件操作） |
| Commit | 提交 |
| Pull request | 拉取请求 |
| Approval | 审批 / 批准（名词 / 操作） |
| Permission | 权限 |
| Sandbox | 沙箱 |
| Full access | 完全访问权限 |
| Settle | 结项 |

同一权限枚举在不同运行器下可能具有不同含义，必须以 `approval-modes.ts` 中的具体策略解释为准，不得统一改写为“自动模式”。删除、退出、覆盖等确认文案必须完整保留作用范围与不可恢复后果。

必须保留的内容：

- PandaCode 及第三方产品、模型和服务名称。
- CLI 参数、工具标识、Git 命令、路径、分支名、URL 和协议枚举。
- `CONTEXT_BOUNDARY` 等提示词与附件解析边界。
- 用户标题、用户消息、代码、模型回答和原始工具输出。
- 系统或第三方错误原始详情。已知自有错误可在完成原始分类后翻译展示，不以模糊英文替换改变错误或业务行为。
- 许可证及版权声明原文。

不得使用全局 DOM 替换、在线机器翻译、原型劫持或修改 IPC 枚举来实现界面本地化。

## 验证

本次通过的检查与尚未完成的原生验收见 [验证记录](localization-verification.md)。

桌面运行类型检查、构建、Node 单元测试和发布脚本测试；已有英文精确断言通过显式英文偏好继续运行。`tests/i18n.test.mjs` 检查字典、参数、格式化、切换通知和生成物。

浏览器测试默认显式选择英文；中文用例自行清除该预设或选择 `zh-CN`。在 Windows 指定 `PANDACODE_TEST_CHROME`，在独立工作树使用独立 `PW_PORT`。浏览器 preview 使用 mock，不能代替 WebView2 原生菜单或安装器验收。

手机单独运行 `npm run typecheck`、`npm test`、`npm run lint`。手机网页或纯函数测试不能代替 iOS / Android 原生导航、权限弹窗和 iOS 实时活动验收。

交付时应分别列出通过的自动化检查、已检查的界面，以及无法运行的原生平台项目；不能把仅翻译部分页面称为完整中文版。
